Web Resume

This project is a personal web-based resume for Aaron Rader. It includes an HTML and CSS-based webpage that presents professional experience, education, and technical skills. Additionally, a downloadable PDF version of the resume is available.

Features

Fully Responsive: The webpage is designed using HTML and CSS.

Downloadable Resume: A PDF version (Aaron_Rader_Resume.pdf) is linked for easy access.

Hosted on Azure: The site is deployed on an Azure web service with an HTTPS-based URL.

Version Control with GitHub: The source files are maintained in this GitHub repository.
